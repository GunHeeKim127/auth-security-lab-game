# 논문 요구사항 충족도 점검

## 점검 기준과 연구 주제

프로젝트에 기록된 연구 범위를 기준으로 논문 주제를 다음과 같이 정규화하였다.

> Next.js와 PostgreSQL 기반 웹 애플리케이션에서 인증·세션·권한 우회 취약점을 재현하고 보안 통제 적용 전후의 효과를 자동화 실험으로 비교하는 연구

정확한 제출용 제목이 별도로 정해져 있다면 제목만 교체하고 아래 범위와 결과의 일치 여부를 다시 확인한다.

## 판정

현재 상태는 **1차 기능 실험과 핵심 통합 실험 완료, 반복 측정 단계 미완료**이다. 16개 공격의 판정 비교와 함께 실제 로그인, PostgreSQL 세션, 객체 권한, JWT 서명, CSRF 흐름과 정상 요청 대조군을 검증했다. 반복 측정과 성능 통계가 아직 없어 최종 논문 실험이 완료됐다고 보기는 어렵다.

| 요구사항 | 상태 | 현재 증거 | 보완 조건 |
|---|---|---|---|
| 연구 목적과 질문 | 충족 | `docs/experiment-design.md` | 제출 양식에 맞게 가설 번호 부여 |
| 비교군 설계 | 충족 | 3001 취약 모드, 3002 강화 모드 | 환경 차이가 `LAB_MODE`뿐인지 지속 확인 |
| 16개 시나리오 분류 | 충족 | `src/lib/scenarios.ts` | 최종 표에 OWASP·CWE 매핑 유지 |
| 자동 공격 실행 | 충족 | Playwright 32개 비교 테스트 | 테스트 실행 로그를 실험 회차별 보존 |
| DB 감사 로그 | 충족 | `AuditLog` 32건, `results/db-verification.json` | 실행 회차 ID를 추가하면 추적성 향상 |
| 실제 PostgreSQL 사용자·리소스 | 충족 | 사용자 3명, 리소스 2개, 실제 조회·수정·삭제 테스트 | 반복 실행 시 시드 복원 유지 |
| 실제 세션 수명 주기 | 충족 | 로그인, 고정 방어, 만료, 로그아웃 폐기, 세션 DB 기록 | 유휴 만료와 다중 장치 정책은 확장 가능 |
| JWT 암호 검증 | 부분 충족 | `jose` 서명·HS256 고정·alg=none 거부 | iss·aud·nbf 실패 사례와 키 회전 추가 |
| CSRF 요청 흐름 | 충족 | 쿠키 토큰, 헤더 토큰, Origin 검증 및 정상 대조군 | 실제 UI 폼 테스트는 확장 가능 |
| 정상 기능 회귀 테스트 | 충족 | 정상 로그인·세션 조회·소유 객체·관리자·JWT·CSRF | 기능 추가 시 지속 확장 |
| 반복 실험과 통계 | 미충족 | 단일 실행 32/32 | 최소 10회 반복, 비율·시간·분산 기록 |
| 성능·사용성 비용 | 미충족 | 측정 없음 | 강화 전후 지연시간과 실패율 비교 |
| 위협 모델과 범위 | 보완 완료 | `docs/paper-security-section.md` | 최종 논문 범위와 일치 확인 |
| 연구 윤리와 안전 | 보완 완료 | 로컬 전용, 비실계정 명시 | 기관 양식이 있으면 추가 반영 |
| 공식 표준 근거 | 보완 완료 | OWASP, NIST, RFC, CWE | 학교 인용 형식으로 변환 |
| 재현 절차 | 부분 충족 | README와 명령 제공 | OS·도구 버전 스냅숏과 반복 실행 스크립트 추가 |
| 결론의 타당성 | 부분 충족 | 100%p 감소 관찰 | 모의 판정 결과와 실제 통합 결과를 분리 보고 |

## 논문 제출 전 필수 보완 순서

1. FLOW-01 비밀번호 재설정 토큰을 실제 DB 모델과 단일 사용 흐름으로 구현한다.
2. AUTH-04 자격 증명 스터핑을 여러 실제 계정으로 확장한다.
3. JWT의 iss·aud·nbf 실패 사례와 키 회전 조건을 추가한다.
4. 각 모드를 최소 10회 반복하고 회차별 JSON을 별도로 저장한다.
5. 공격 성공률, 정상 요청 성공률, 응답시간 중앙값과 범위를 계산한다.
6. 반복 통합 결과가 나온 뒤 초록·결론의 수치를 확정한다.

## 결론 사용 제한

현재 확인된 “취약 모드 100%, 강화 모드 0%”는 구현한 16개 판정 조건에 대한 1차 결과다. 이를 일반적인 웹 애플리케이션 전체의 취약점 감소율로 표현하면 안 된다. 최종 논문에서는 “본 로컬 실험 환경과 정의된 공격 입력에서 관찰된 값”으로 범위를 제한한다.
