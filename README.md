# 로그인 너머: 웹서비스 방어전

논문 **「웹 애플리케이션의 인증·인가 우회 경로 분석 및 다중 보안 통제 적용에 따른 취약점 개선 효과 평가」**의 실험 결과를 누구나 직접 체험할 수 있게 만든 교육용 전략 게임입니다.

이 앱은 **웹서비스를 개발하거나 보안을 배우는 사람이 방어 장치를 조합하고 16개 우회 공격을 실행해 보면서, 인증·인가만 강화했을 때 남는 위험과 다중 통제의 효과를 이해하도록 돕습니다.**

## 사용자가 할 일 세 가지

1. **방어 장치 배치:** 20포인트 안에서 원하는 통제를 선택합니다.
2. **공격 웨이브 실행:** 16개 인증·세션·권한·토큰 공격이 서버로 이동하는 과정을 봅니다.
3. **결과 비교·학습:** 서버 체력과 차단 결과를 확인하고 공격 도감에서 원인과 방어 원리를 읽습니다.

## 논문 결과가 적용된 방식

논문은 각 조건에서 16개 공격을 10회씩, 총 480건 관찰했습니다. 앱은 같은 16개 공격 경로와 통제 대응표를 게임 규칙으로 사용합니다.

| 실험 조건 | 공격 성공 | 성공률 | 게임에서 확인하는 방법 |
|---|---:|---:|---|
| 무방비 | 160/160 | 100% | `무방비` 프리셋 |
| 인증·인가만 강화 | 80/160 | 50% | `인증·인가 요새` 프리셋 |
| 다중 통제 적용 | 0/160 | 0% | `다중 통제 완성` 프리셋 |

한 번의 게임 웨이브는 각 공격 경로를 한 번씩 실행합니다. 논문 수치는 이 16개 경로를 조건별로 10회 반복한 집계입니다. 게임의 목적은 **인증·인가 통제만으로는 세션·토큰·요청 흐름의 8개 경로가 남으며, 서로 다른 계층을 함께 방어해야 전체 경로를 막을 수 있다**는 결과를 체험하는 것입니다.

앱에 쓰인 데이터는 공격 분류와 집계 수치뿐이며 실제 개인정보는 없습니다. 외부 API, 계정, 데이터베이스, API 키도 필요하지 않습니다.

## 실행 방법

Node.js 20 이상에서 다음 명령을 실행합니다.

```powershell
npm install
npm run dev
```

브라우저에서 `http://localhost:3001`을 엽니다. 3001번 포트를 사용 중이면 다음처럼 다른 포트를 지정할 수 있습니다.

```powershell
npx next dev -p 3010
```

## 앱으로 설치하기 (PWA)

Vercel의 HTTPS 주소를 Chrome 또는 Edge에서 열면 별도의 앱처럼 설치할 수 있습니다.

- **Windows / Android:** 주소창의 설치 아이콘을 누르거나 화면 상단의 `앱 설치` 버튼을 누릅니다.
- **iPhone / iPad:** Safari의 공유 버튼에서 `홈 화면에 추가`를 선택합니다.
- 설치 후 홈 화면 또는 시작 메뉴에서 `로그인 너머`를 실행할 수 있습니다.
- 한 번 정상 실행한 뒤에는 네트워크가 끊겨도 캐시된 게임 화면 또는 오프라인 안내 화면이 열립니다.

PWA 설치에는 배포된 HTTPS 주소가 필요합니다. `localhost`에서도 개발 검증은 가능하지만 일반 LAN 주소의 HTTP 접속은 설치 대상이 아닙니다.
## 빠른 통과 확인

1. 첫 화면에서 논문 제목, 대상 사용자, 사용 순서 세 가지를 확인합니다.
2. `인증·인가 요새` → `공격 웨이브 시작`을 누릅니다. 16개 중 8개가 서버에 도달하고 서버 체력이 감소하면 통과입니다.
3. `다중 통제 완성` → `공격 웨이브 시작`을 누릅니다. 16개가 모두 차단되고 `PERFECT DEFENSE`가 나오면 통과입니다.
4. 공격 도감에서 아무 카드를 선택합니다. 취약 원인·공격 방식·방어 원리가 나오면 통과입니다.

## 폴더 안내

- `src/app/page.tsx`: 게임 규칙과 사용자 상호작용
- `src/app/globals.css`: 전투 화면과 애니메이션
- `src/lib/scenarios.ts`: 16개 예시 공격 경로
- `data/research-summary.json`: 논문 집계값과 앱 적용 규칙
- `docs/BRB_SUBMISSION.md`: 과제 체크리스트, 제출문, 확인 기록

이 프로젝트의 공격 표현은 로컬 교육용 모의 시나리오입니다. 외부 서비스에 공격 요청을 보내지 않습니다.
