# 로그인 너머 웹서비스 방어전

인증·인가 우회 경로와 다중 보안 통제의 효과를 체험하는 교육용 전략 게임입니다. 김건희의 연구에서 확인한 세 조건의 결과를 게임 규칙으로 사용합니다.

- 취약 모드: 160/160 공격 성공, 성공률 100%
- 인증·인가 부분 강화: 80/160 공격 성공, 성공률 50%
- 전체 다중 통제: 0/160 공격 성공, 성공률 0%

## 게임 방법

1. 20포인트의 예산으로 방어 카드를 선택합니다.
2. 공격 웨이브를 실행합니다.
3. 남은 우회 경로와 방어 점수를 확인합니다.
4. 공격 도감에서 각 취약 원인, 공격 경로, 해결 방법을 확인합니다.
5. 연구 프리셋으로 취약·부분 강화·전체 강화 결과를 비교합니다.

## 실행

```powershell
npm install
npm run dev
```

브라우저에서 `http://localhost:3001`을 엽니다.

## 검증

```powershell
npx tsc --noEmit --incremental false
npm run build
```

실제 계정이나 외부 서비스를 공격하지 않으며, 프로젝트에 정의된 안전한 로컬 시나리오만 사용합니다.
